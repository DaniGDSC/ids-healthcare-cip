## VẤN ĐỀ GỐC RỄ
================================================================================

Trong detection_engine/engine.py:275:
    c_detect = max(c_track_a, c_track_b)

Lấy max() là phép so sánh "táo và cam" vì:
- c_track_a (XGBoost): calibrated probability — đúng nghĩa P(attack | features)
- c_track_b (DAE): min-max scaled reconstruction error trên benign training
  errors (xem module2_detection/models/DAE.py:421-430). KHÔNG phải xác suất.

Hệ quả: c_track_b = 0.7 không có nghĩa "70% xác suất attack" — có thể chỉ
là 5–15% xác suất thật. Khi fused bằng max(), DAE elevate sai rất nhiều
flow benign biên → 2066 false positives ở LOW tier.

Bằng chứng phụ: dynamic_threshold_results.json cho thấy adaptive threshold
đã được thử và làm tệ hơn (F1: 0.51 → 0.37). Vì nó tune trên scale không
calibrated → vô nghĩa.

    def tune_tier_thresholds(R_val, y_val, targets):
        sorted_R = np.sort(np.unique(R_val))[::-1]
        thresholds = {}
        for tier, p_target in sorted(targets.items(), key=lambda x: -x[1]):
            for tau in sorted_R:
                mask = R_val >= tau
                if mask.sum() < 50:    # min support
                    continue
                prec = y_val[mask].mean()
                if prec >= p_target:
                    thresholds[tier] = float(tau)
                    break
        return thresholds

3.2 Tạo plausibility.py:
    def apply_plausibility_gate(R, tiers, biometric_z, sigma, gated_tiers):
        in_scope = np.array([t in gated_tiers for t in tiers])
        clinically_normal = (np.abs(biometric_z).max(axis=1) < sigma)
        gated_mask = in_scope & clinically_normal
        new_tiers = tiers.copy()
        new_tiers[gated_mask] = "NORMAL"
        return new_tiers, gated_mask

3.3 Tính biometric_z:

   - Hiện tại 15% × 16318 = ~2447 samples → đủ cho isotonic regression

3. Threshold tuning metric: precision-only vs cost-weighted F-score.
   - Khuyến nghị: precision-only với min support 50 (đơn giản, defensible)

4. Plausibility sigma:
   - Đề xuất 1.0σ (stricter than SIGMA_THRESHOLD=1.5)
   - Có thể tune trên val set nếu thấy demote rate quá cao/thấp

5. Periodic recalibration policy:
   - Đề xuất: monthly cron job re-fit calibrator nếu Brier drift > 0.05
   - Implement sau khi có production logs
